# S.I.P.D. — Sistema Integral de Procesos Disciplinarios

Sistema web desarrollado para el área de Recursos Humanos / Coordinación de **Cootranshuila LTDA**,
orientado a la gestión, seguimiento y control de procesos disciplinarios aplicados a los
conductores de la empresa.

## 📋 Descripción

El sistema centraliza y automatiza el ciclo completo de un proceso disciplinario: desde el
registro de la falta hasta la decisión final, incluyendo la gestión de los abogados
responsables y estadísticas generales para la toma de decisiones.

## ✨ Módulos principales

- **Gestión de abogados:** registro, edición y eliminación de abogados coordinadores de los
  procesos disciplinarios.
- **Registro de proceso disciplinario:** formulario con información del conductor (nombre,
  cédula, modalidad/cargo, placa del vehículo, ruta, teléfono), datos de la falta (tipo, fecha,
  descripción, carga de documento soporte) y del proceso (observaciones, descargos, decisión final).
- **Consulta de procesos disciplinarios:** búsqueda y seguimiento de casos registrados.
- **Estadísticas de procesos disciplinarios:** panel con filtros por rango de fechas y por
  modalidad/cargo, con gráficas de comparación por estado (pendientes, en proceso, sancionados,
  archivados) y distribución porcentual general.

## 🛠️ Tecnologías utilizadas

- **Backend:** PHP, Laravel
- **Frontend:** JavaScript, HTML, CSS, Bootstrap
- **Base de datos:** MySQL
- **Visualización de datos:** gráficas estadísticas (barras y torta) para reportes
